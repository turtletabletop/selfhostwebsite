- Home
- Projects
- Contact me!
- Testzone

### Home
Contains links to all the other parts of the website, and contains a little description about me.

### Projects

### Contact me!

### Testzone
This is where a lot of testing for my site happens! It's my dumping ground for wacky website things to happen.
